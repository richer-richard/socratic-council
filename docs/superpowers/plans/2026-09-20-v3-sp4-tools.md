# v3 Sub-project 4: Tools Depth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The seats' hands get sharper and safer: web search that is not geo-localised and has a stable reference backend, a shell sandbox that is tighter (no keychain or directory-service reads) and more usable (the Xcode shims and user lookups work) with a Linux sandbox through bubblewrap, a document deliverable that reads like a document, a hand-off folder every run leaves behind (and a command that rebuilds one from any stored session), and a `probe --tools` that proves the tool-result round trip on every provider's client style.

**Architecture:** Everything lands in the engine crate so both surfaces benefit; the CLI grows a `handoff` command and a `--handoff` flag and renders the new `Handoff` event; the desktop reducer ignores the event (it never throws on an unknown one) and gains nothing else this cycle.

**Tech Stack:** Rust, reqwest, tokio, serde_json, `sandbox-exec` (macOS), `bwrap` (Linux), the fake-provider integration test.

**Spec:** `docs/superpowers/specs/2026-09-19-one-engine-structured-deliberation-design.md` (sections 6, 7 and 12.4)

**Status:** complete. Task 1 70a9fe3, Task 2 771e6ed, Task 3 f5cc0a3, Task 4 9d670c6, Task 5 (see git log), Task 6 in the commit that carries this line. Left out of Task 3: renaming the session after the document title (low value; the topic stays the title).

## Global Constraints

- Tool results stay untrusted data: every backend's output passes `clean_output` (terminal sanitiser, directive neutraliser, cap) and is fenced before a model sees it.
- Every outbound query passes `guard_outbound_query`; no new backend receives anything else.
- The shell never gets network; writes stay inside the workspace (plus the narrow Xcode-shim cache path on macOS); the record says so when a command ran unsandboxed.
- Keys never reach a tool, a hand-off file or a log.
- Gates: `cargo fmt --all --check`, `cargo test --locked --workspace`, `cargo test --locked -p socratic-council --no-default-features`, `cargo clippy --workspace --all-targets --locked -- -D warnings` (both feature sets), `cargo audit --deny warnings`, plus `cd apps/desktop/src-tauri && cargo test --lib && cargo clippy --all-targets -- -D warnings` (the engine is a path dependency). `cargo clean` at the root and in `src-tauri` after the last task.
- Commits carry no attribution trailers.
