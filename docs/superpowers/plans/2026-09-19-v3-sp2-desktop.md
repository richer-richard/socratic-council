# v3 Sub-project 2: Desktop on the Shared Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The desktop app convenes the council through the Rust engine crate hosted in its Tauri backend, renders the engine's event stream on a new Session page, edits the roster and tool policy in Settings, and sheds the TypeScript engine.

**Architecture:** `apps/desktop/src-tauri` depends on `engine/` by path and exposes `engine_start` / `engine_input` / `engine_cancel` / `engine_catalog` / `engine_scan`; runs emit `engine://event` envelopes. The front end gets `services/engine.ts` (typed events, start, input, cancel, subscribe), a `Session` page driven by a pure event reducer, a roster editor in the settings modal, and a config store with `roster`, `moderator`, `utility`, `tools`, `protocol`. Sessions keep flowing through `services/sessions.ts` (the engine's v2 file is imported when the run finishes) so the sidebar, projects, exports and bundles keep working. API keys stay in the webview's encrypted store and are handed to the engine per run.

**Tech Stack:** Tauri 2 (Rust, tokio), React 19 + TypeScript + Vite + Tailwind, vitest, the `socratic-council-engine` crate.

**Spec:** `docs/superpowers/specs/2026-09-19-one-engine-structured-deliberation-design.md` (sections 3, 8, 9, 11)

## Global Constraints

- The webview keeps no direct network path and its strict CSP; provider calls happen only in the engine (Rust). The existing broker (`http.rs` + `allowlist.rs`) stays for the settings "test connection" and the live model scan until `engine_scan` replaces the scan.
- Keys are never logged or emitted; the engine host zeroises the key map when a run ends; error strings go through `redact.rs` before reaching the webview.
- Never fabricate model ids; the catalog comes from `engine_catalog` (verified rows) merged with live scans.
- Gates: `pnpm install --frozen-lockfile && pnpm format:check && pnpm lint && pnpm typecheck && pnpm test && pnpm build`, then `cd apps/desktop/src-tauri && cargo test --lib && cargo clippy --all-targets -- -D warnings && cargo audit --deny warnings`, plus the root Rust workspace gates. The lint `--max-warnings` ratchet is lowered to the real count after the cut list lands.
- Commits carry no attribution trailers. `cargo clean` in `apps/desktop/src-tauri` after Task 1 and after Task 4; `rm -rf apps/desktop/node_modules/.vite apps/desktop/dist` after Task 3.

    pub topic: String, pub roster: Roster, pub keys: HashMap<Provider, String>,

The run's store is `SessionStore::at(app_data_dir/sessions, dek, SharedWithApp)` with the DEK from `vault_file`; the workspace is `app_data_dir/workspaces/<session_id>`; the daily ledger dir is `app_data_dir`. Events: `app.emit("engine://event", Envelope)`. Errors emitted or returned pass through `redact::scrub_known(&text, &keys)`.
